# Content

This directory holds the source-of-truth content bundles that
`services/ingestion` imports into PostgreSQL. Nothing here is generated by a
model, and nothing here is edited by the running application.

## The authoritative flag

Every bundle declares `"authoritative": true | false`.

- **`false`** — the content has **not** been checked against a printed or
  otherwise authoritative edition. The importer forces every record from such a
  bundle to `verification_status: "draft"`, and the API refuses to promote it to
  `verified` or `published`. Development placeholders live here.
- **`true`** — a named reviewer has checked the text against the source recorded
  in `sources[]`, and the licence permits redistribution.

**Everything currently in this directory is `authoritative: false`.** The
records exist so the schema, the reader, the search pipeline and the Ask
pipeline can be exercised end to end. They are *not* a publishable edition of
the Bhagavad Gita.

## What is still needed

To ship, this directory needs a complete, licence-cleared dataset:

| File | Needs |
| --- | --- |
| `canonical/verses.*.json` | All 700 verses in Devanagari, from one identified edition, proofread against it |
| `canonical/transliteration.*.json` | Verified IAST for all 700 verses |
| `translations/*.json` | At least one public-domain or licensed English translation and one Hindi translation |
| `commentaries/*.json` | Commentary the project has the right to redistribute |
| `canonical/words.*.json` | Word-by-word meanings |

Public-domain options exist (for example, translations published before the
relevant copyright cutoff), but the edition, its scan, and its licence status
must be recorded in `sources[]` before import. **Do not scrape a modern
translation.** Most contemporary English and Hindi translations of the Gita are
in copyright; using one requires written permission, recorded in the source's
`copyrightStatus` and `verificationNotes`.

## Layout

```
content/
  canonical/      chapter metadata, Sanskrit verse text, transliteration
  translations/   per-language, per-translator translation bundles
  commentaries/   per-commentator commentary bundles
  topics/         curated life-situation topics and their verse mappings
  glossary/       Sanskrit term definitions
```

## Importing

```bash
cd apps/api
python -m scripts.import_content ../../content/canonical/chapters.json
python -m scripts.import_content ../../content --all
```

The importer is idempotent: re-running a bundle updates changed rows and leaves
everything else alone. Any change to existing canonical text writes a
`content_change_log` row holding the previous value, the new value, the editor
and the reason.
